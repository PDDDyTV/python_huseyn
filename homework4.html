Задачи по теме "Списки" в Python (средний уровень)

1. Фильтрация списка по условию

Дан список целых чисел.
Задача: создать новый список, содержащий только числа, которые делятся на 3 и являются положительными.
Пример: [3, -6, 10, 12, 0, 7] → [3, 12]

2. Подсчёт уникальных элементов

Дан список строк.
Задача: определить, сколько уникальных слов содержится в списке (без учёта регистра).
Пример: ["Привет", "мир", "привет", "Питон"] → 3

3. Сдвиг элементов вправо

Дан список чисел и число k.
Задача: выполнить циклический сдвиг списка вправо на k позиций.
Пример: [1, 2, 3, 4, 5], k = 2 → [4, 5, 1, 2, 3]

4. Перемешивание соседних элементов

Дан список чисел чётной длины.
Задача: обменять местами элементы попарно: 1-й ↔ 2-й, 3-й ↔ 4-й и т. д.
Пример: [10, 20, 30, 40] → [20, 10, 40, 30]

5. Поиск двух минимальных элементов

Дан список из разных чисел.
Задача: найти два наименьших числа из списка без использования сортировки.

6. Максимальная длина возрастающей подпоследовательности

Дан список чисел.
Задача: определить длину самой длинной последовательности подряд идущих элементов, которая строго возрастает.
Пример: [1, 2, 2, 3, 4, 1] → 3 (последовательность 2, 3, 4)
