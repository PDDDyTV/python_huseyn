Списки в Python — начальная теория

Список — это упорядоченная изменяемая коллекция элементов. В одном списке можно хранить числа, строки, логические значения и даже другие списки.

1. Создание списков

Через квадратные скобки:

a = [1, 2, 3, 4]

Пустой список:

empty = []
empty2 = list()

2. Индексация элементов

Элементы списка нумеруются с нуля:

[10, 20, 30, 40]
  0   1   2   3

Доступ по индексу:

a = [10, 20, 30]
print(a[1])   # 20

Отрицательные индексы:

a[-1]  # последний элемент
a[-2]  # предпоследний

3. Изменение элементов

Списки можно изменять:

a = [5, 6, 7]
a[1] = 10
# результат: [5, 10, 7]

4. Основные операции со списками

Добавление элементов

a.append(100)      # добавить в конец
a.insert(1, 50)    # вставить по индексу

Удаление элементов

a.remove(5)        # удалить первое совпадение
a.pop(2)           # удалить по индексу
a.pop()            # удалить последний элемент

Длина списка

len(a)

5. Перебор списка циклом

Перебор по элементам

a = [10, 20, 30]
for x in a:
    print(x)

Перебор по индексам

a = [10, 20, 30]
for i in range(len(a)):
    print(i, a[i])

6. Срезы (slice)

Позволяют получить часть списка:

a = [1, 2, 3, 4, 5]

a[1:4]    # [2, 3, 4]
a[:3]     # [1, 2, 3]
a[2:]     # [3, 4, 5]
a[:]      # копия списка

С шагом:

a[::2]    # [1, 3, 5]
a[::-1]   # список в обратном порядке

7. Операции со списками

Конкатенация

[1, 2] + [3, 4]   # [1, 2, 3, 4]

Повторение

[0] * 5           # [0, 0, 0, 0, 0]

Итоги

  • Список — упорядоченная коллекция
  • Индексация начинается с нуля
  • Списки можно изменять
  • Поддерживают добавление, удаление, срезы, перебор
